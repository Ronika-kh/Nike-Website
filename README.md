# Nike-Inspired E-Commerce Website

A simple Nike-inspired e-commerce website built with HTML and CSS as a front-end learning project.

> This is an educational project and is not an official Nike website.

## Features

- Home page
- Products page
- About Us page
- Registration page
- Product cards and prices
- Navigation between pages
- Font Awesome icons


## Technologies

- HTML5
- CSS3
- Responsive Web Design
- Font Awesome

## Project Structure

```text
Nike-Website/
├── index.html
├── products.html
├── about.html
├── register.html
├── css/
│   ├── style.css
│   ├── products.css
│   ├── about.css
│   └── register.css
├── images/
│   └── product and website images
└── README.md
```

## How to Run

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
